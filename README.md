Entry for make.fun's **"Dad Joke Showdown"** bounty ($5 in USDC, 3 places paid):
a program that writes one dad joke (at most 200 characters) to `/output/entry.txt`.

## The joke

> I told my kids I used to be a baker, but I couldn't make enough dough — so now I just loaf around the house and call it quality time.

## How it works

`main.py` writes the joke above to `/output/entry.txt` (UTF-8, 133 characters).
An AI judge compares entries two at a time and picks the one that lands the bigger groan.
